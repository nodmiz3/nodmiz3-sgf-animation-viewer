# SGF Animation Viewer
SGF（囲碁棋譜）をブラウザでアニメーション再生できる軽量ビューアです。  
punigo.app や Lizzie、Sabaki などで出力した SGF をそのまま貼り付けて再生できます。

---

## ✨ 特徴
- SGF を **ペーストするだけ**で再生
- **盤サイズを自動判定**（SZ[6], SZ[9], SZ[13], SZ[19] など）
- 手順を **自動アニメーション再生**
- **1手ずつ進める**ステップ再生
- パス（W[] / B[]）にも対応
- 完全クライアントサイド（サーバ不要）
